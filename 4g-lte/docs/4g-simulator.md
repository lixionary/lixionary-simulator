4G LTE OFDM Physical Layer (PHY) Transceiver Simulation Specification
1. Executive Summary & Architecture Overview
This document defines the complete end-to-end technical architecture for the educational 4G LTE Orthogonal Frequency Division Multiplexing (OFDM) Physical Layer (PHY) Transceiver Simulator. It integrates both the baseline simulation pipeline and all advanced 3GPP-inspired physical layer enhancements across seven processing stages and a configurable wireless multipath channel.
End-to-End Signal Processing Pipeline
* Stage 1 (TX Transport Block & Channel Coding): ASCII/Binary Source → CRC-8/16 Checksum Attachment → Forward Error Correction (Hamming(7,4) or Convolutional (2,1,3) Encoder) → Gold Sequence Bit Scrambling.
* Stage 2 (Modulation Mapper): I/Q Bit-Splitting → Gray-Coded Constellation Mapping (BPSK, QPSK, 16-QAM, 64-QAM, 256-QAM).
* Stage 3 (2D LTE Resource Grid Mapper): 12 × 7 Physical Resource Block (PRB) Allocation → CRS Pilot Insertion → PDCCH Control Region (Symbols 0–1) → PSS/SSS Synchronization Signals → DC & Guard Band Nulling.
* Stage 4 (OFDM Baseband Modulator): Zero-Padded 64-Point IFFT → Normal vs. Extended Cyclic Prefix (CP) Insertion → Peak-to-Average Power Ratio (PAPR) Measurement.
* Center Stage (4G Wireless Channel): Configurable Multipath Delay Profile (AWGN, EPA, ETU, and Custom Tap Editor) → Inter-Symbol Interference (ISI) Modeling (when Delay Spread > CP) → Carrier Frequency Offset (CFO) Injection → Additive White Gaussian Noise (AWGN).
* Stage 5 (OFDM Receiver & Equalizer): CP Removal & Timing Window → 64-Point FFT & Guard Stripping → CRS Pilot Channel Estimation & 2D Interpolation → Zero-Forcing (ZF) vs. Minimum Mean Square Error (MMSE) Equalization → 2D Channel Frequency Response H(f) Visualization.
* Stage 6 & Stage 7 (Demapper, FEC Decoder & Sink): Hard Euclidean Distance & Soft Log-Likelihood Ratio (LLR) Demapping → EVM (% RMS) Calculation → Descrambling → Viterbi / Hamming FEC Decoding → CRC Verification Badge → Bit Error Rate (BER) & ASCII Reconstruction.
2. Stage 1: Transport Block, CRC, FEC Coding & Bit Scrambling (TX Source)
2.1 Inputs & Configuration Parameters
* Source Mode: User ASCII string (8 bits per character) or custom binary string of 0s and 1s.
* CRC Mode: None, CRC-8 (polynomial x⁸ + x² + x + 1, hex 0x07), or CRC-16-CCITT (polynomial x¹⁶ + x¹² + x⁵ + 1, hex 0x1021).
* FEC Coding Scheme: Uncoded (Rate 1), Hamming(7,4) Block Code (Rate 4/7), or Rate 1/2 Convolutional Code with constraint length K = 3 and generator polynomials G₁ = (111)₂ = 7₈ and G₂ = (101)₂ = 5₈.
* Scrambling Seed: 31-bit Gold sequence initialization seed c_init (based on Physical Cell ID N_ID^cell and slot number n_s).
2.2 Processing Logic
1. Binary Serialization: Convert each input ASCII character into an 8-bit MSB-first binary sequence b₀, b₁, ..., b_{A-1}.
2. CRC Attachment: Compute the L-bit cyclic redundancy check (L = 8 or 16) over the payload bits and append parity bits p₀, ..., p_{L-1} to form the Transport Block c₀, ..., c_{B-1}, where B = A + L.
3. Forward Error Correction (FEC) Encoding:
   * Hamming(7,4) Mode: Group bits into 4-bit nibbles (d₁, d₂, d₃, d₄) and append 3 parity bits:
      * p₁ = d₁ ⊕ d₂ ⊕ d₄
      * p₂ = d₁ ⊕ d₃ ⊕ d₄
      * p₃ = d₂ ⊕ d₃ ⊕ d₄
   * Convolutional (2,1,3) Mode: Pass each input bit u_k through a 2-stage shift register initialized to 00, producing two output coded bits per input bit:
      * v_k⁽¹⁾ = u_k ⊕ u_{k-1} ⊕ u_{k-2}
      * v_k⁽²⁾ = u_k ⊕ u_{k-2}
4. Rate Matching & PRB Padding: Pad or puncture the coded sequence to match the exact bit capacity of the available Data Resource Elements (N_data_RE × M bits, where M is bits per symbol).
5. Gold Sequence Bit Scrambling: XOR the rate-matched bitstream d(i) with a pseudo-random scrambling sequence c(i) generated by modulo-2 addition of two length-31 m-sequences:
   * b̃(i) = (d(i) + c(i)) mod 2
   * Eliminates long runs of identical bits, preventing DC spikes and stabilizing transmit power across subcarriers.
3. Stage 2: Gray-Coded QAM Modulation Mapper & I/Q Bit-Splitting
3.1 Supported Modulation Orders
* BPSK (M = 1 bit/symbol): Maps {0, 1} to I in {-1, +1}, Q = 0. Normalization factor: 1.
* QPSK (M = 2 bits/symbol): Splits 2-bit word (b₀, b₁) into I-branch (b₀) and Q-branch (b₁). Maps {0, 1} to {-1, +1}. Normalization factor: 1 / √2.
* 16-QAM (M = 4 bits/symbol): Splits 4-bit word (b₀, b₁, b₂, b₃) into I-bits (b₀, b₂) and Q-bits (b₁, b₃). Maps 2-bit Gray pairs {00, 01, 11, 10} to {-3, -1, +1, +3}. Normalization factor: 1 / √10.
* 64-QAM (M = 6 bits/symbol): Splits 6-bit word into 3 I-bits and 3 Q-bits. Maps 3-bit Gray triplets {000, 001, 011, 010, 110, 111, 101, 100} to {-7, -5, -3, -1, +1, +3, +5, +7}. Normalization factor: 1 / √42.
* 256-QAM (M = 8 bits/symbol): Splits 8-bit word into 4 I-bits and 4 Q-bits. Maps 4-bit Gray nibbles to odd integers {-15, -13, ..., +13, +15}. Normalization factor: 1 / √170.

4. Stage 3: 2D LTE Resource Grid Mapper & Control/Sync Channels
4.1 Resource Grid Dimensions
   * Active PRB Grid: K = 12 subcarriers (15 kHz spacing = 180 kHz bandwidth) × L = 7 OFDM symbols (Normal CP = 0.5 ms slot) or L = 6 OFDM symbols (Extended CP).
   * Full FFT Subcarrier Allocation (64-Point FFT Frame):
   * Index 0: DC Subcarrier (Null / Zero-Valued to prevent local oscillator leakage).
   * Indices 1 to 6: Positive active subcarriers (+15 kHz to +90 kHz).
   * Indices 58 to 63: Negative active subcarriers (-90 kHz to -15 kHz).
   * Indices 7 to 57: Upper and lower Guard Band Null subcarriers (Zero-padded to prevent adjacent channel interference).
4.2 Physical Channels & Reference Signals inside the PRB
   1. Cell-Specific Reference Signals (CRS Pilots):
   * Fixed known complex symbols P_ref = 1.0 + j 0.0 inserted at Antenna Port 0 coordinates:
   * Symbol l = 0: Subcarriers k in {0, 3, 6, 9} (4 REs)
   * Symbol l = 4 (or l = 3 for Extended CP): Subcarriers k in {1, 4, 7, 10} (4 REs)
   2. PDCCH Control Region (Optional Toggle: CFI = 0, 1, or 2):
   * Occupies the first 1 or 2 OFDM symbol columns (l = 0, 1), excluding CRS pilot REs.
   * Modulated using QPSK to carry Downlink Control Information (DCI) metadata.
   3. PSS / SSS Synchronization Signals (Optional Slot 0 / Slot 10 Toggle):
   * Primary Synchronization Signal (PSS): Zadoff-Chu sequence mapped to the last OFDM symbol (l = 6) of the slot:
   * d_u(n) = exp(-j · π · u · n · (n + 1) / 63)
   * Secondary Synchronization Signal (SSS): Interleaved m-sequences mapped to symbol l = 5 for frame timing and Cell ID detection.
   4. PDSCH User Data REs:
   * All remaining unreserved Resource Elements are populated sequentially with the user's modulated QAM symbols X[k, l].
5. Stage 4: OFDM Baseband Modulation (64-Point IFFT, CP & PAPR)
5.1 Zero-Padded 64-Point IFFT Synthesis
   1. For each OFDM symbol column l, map the 12 active subcarriers X[k, l] into a 64-element frequency vector X_64[m, l] with DC (m = 0) and guard bands (m = 7..57) set to zero.
   2. Compute the 64-point Inverse Fast Fourier Transform (IFFT) to obtain oversampled time-domain baseband samples:
   * x_l[n] = (1 / √N_FFT) · ∑_{m=0}^{63} X_64[m, l] · exp(j · 2 · π · m · n / 64), for n = 0, ..., 63.
5.2 Normal vs. Extended Cyclic Prefix (CP) Toggle
   * Normal CP Mode (7 symbols/slot): Prepends the last N_CP = 16 samples of the 64-sample IFFT block to the front of the symbol, creating an 80-sample OFDM symbol (~4.7 microseconds guard interval in standard LTE).
   * Extended CP Mode (6 symbols/slot): Prepends the last N_CP = 32 samples of the 64-sample IFFT block, creating a 96-sample OFDM symbol (~16.67 microseconds guard interval) designed for severe delay spread in large cells.
   * Mathematical Operation:
   * x_{CP, l}[n] = x_l[n + N_FFT - N_CP] for 0 ≤ n < N_CP
   * x_{CP, l}[n] = x_l[n - N_CP] for N_CP ≤ n < N_FFT + N_CP
5.3 Peak-to-Average Power Ratio (PAPR) Meter
   * Computes the instantaneous power P[n] = |x_{CP}[n]|² across the entire transmitted slot and reports:
   * PAPR (dB) = 10 · log₁₀( max_n(|x[n]|²) / mean_n(|x[n]|²) )
   * Highlights high-PAPR envelope peaks caused by constructive interference of aligned subcarriers and illustrates why LTE uses SC-FDMA on the uplink.
6. Center Stage: 4G Wireless Multipath, ISI, CFO & AWGN Channel
6.1 Multipath Delay Profiles & Manual Tap Editor
The time-domain transmit signal x_{CP}[n] is convolved with a discrete-time Channel Impulse Response (CIR) h[d] = ∑_{p=0}^{P-1} α_p · δ[d - τ_p]:


   * AWGN Only (Line-of-Sight): 1 tap at delay τ₀ = 0, gain |α₀| = 1.0, phase = 0 rad.
   * EPA (Extended Pedestrian A): 3 taps at delays τ = {0, 2, 5} samples with relative power {0 dB, -7 dB, -15 dB} (stays strictly within Normal CP).
   * ETU (Extended Typical Urban): 4 taps at delays τ = {0, 4, 10, 15} samples with deep frequency-selective notches across the 12 subcarriers.
   * Manual Tap Delay/Gain Editor & ISI Demonstration Mode:
   * Users can manually adjust tap delays τ_p from 0 to 28 samples and tap gains |α_p| in [0, 1].
   * Inter-Symbol Interference (ISI) Demo: When any tap delay τ_p exceeds N_CP (e.g., τ_p = 22 samples while Normal CP = 16 samples), energy from OFDM symbol l - 1 spills into the active FFT window of symbol l, destroying subcarrier orthogonality and creating an irreducible error floor even at infinite SNR.
6.2 Carrier Frequency Offset (CFO) Slider
   * Models local oscillator mismatch or Doppler shift ε (normalized to subcarrier spacing Δf = 15 kHz, adjustable from -0.50 to +0.50):
   * y_{CFO}[n] = y_{multipath}[n] · exp(j · 2 · π · ε · n / N_FFT)
   * Causes progressive phase rotation in time and Inter-Carrier Interference (ICI) in the FFT output.
6.3 Additive White Gaussian Noise (AWGN)
   * Adds complex circularly symmetric Gaussian noise w[n] ~ CN(0, σ_n²) scaled according to the user's SNR (dB) setting:
   * σ_n² = P_signal · 10^(-SNR_dB / 10)
   * y[n] = y_{CFO}[n] + w[n]
7. Stage 5: Receiver FFT, 2D Channel Estimation & ZF vs. MMSE Equalization
7.1 CP Removal & 64-Point FFT
   1. CFO Compensation (Optional Toggle): Multiplies received samples by exp(-j · 2 · π · ε̂ · n / N_FFT).
   2. Cyclic Prefix Stripping: Discards the first N_CP samples of each OFDM symbol block, extracting the 64-sample observation window.
   3. 64-Point Forward FFT & Guard Removal: Computes the 64-point FFT and extracts the 12 active subcarriers Y[k, l], discarding the DC null and 50 guard-band subcarriers.
7.2 2D Pilot Channel Estimation & H(f) Plot
   1. Least-Squares (LS) Pilot Estimation: At the 8 CRS pilot positions (k_p, l_p), computes:
   * Ĥ_LS[k_p, l_p] = Y[k_p, l_p] / P_ref
   2. 2D Time-Frequency Bilinear Interpolation:
   * First interpolates linearly across frequency subcarriers k = 0..11 within pilot-bearing symbols (l = 0 and l = 4).
   * Then interpolates linearly across time symbols l = 0..6 for each subcarrier k to form the complete 12 × 7 channel estimate matrix Ĥ[k, l].
   3. Interactive Channel Frequency Response H(f) Visualization:
   * Plots the true channel magnitude |H(k)| (dB) and phase angle(H(k)) (degrees) alongside the pilot-interpolated estimate |Ĥ(k)| across all 12 subcarriers.
7.3 Equalizer Mode Comparison: Off vs. Zero-Forcing (ZF) vs. MMSE
   * Equalizer OFF: X̂[k, l] = Y[k, l] (constellation remains rotated and scaled by multipath fading).
   * Zero-Forcing (ZF) Equalizer:
   * Weight: W_ZF[k, l] = Ĥ*[k, l] / |Ĥ[k, l]|²
   * Perfectly inverts channel phase and amplitude, but suffers from severe noise amplification when a subcarrier experiences a deep fade (|Ĥ[k, l]| → 0).
   * Minimum Mean Square Error (MMSE) Equalizer:
   * Weight: W_MMSE[k, l] = Ĥ*[k, l] / (|Ĥ[k, l]|² + (1 / SNR_linear))
   * Regularizes the denominator using the estimated noise variance (1 / SNR_linear), preventing noise explosion in deep spectral nulls and minimizing overall symbol error rate.
8. Stage 6 & Stage 7: Soft LLR Demapping, FEC Decoding & CRC Verification Sink
8.1 Hard-Decision & Soft-Decision LLR Demapper (Stage 6)
   1. Error Vector Magnitude (EVM % RMS):
   * EVM (%) = √( ∑(|X̂[n] - X_ideal[n]|²) / ∑(|X_ideal[n]|²) ) · 100%
   2. Hard-Decision Euclidean Demapping:
   * Selects constellation symbol c_i minimizing |X̂ - c_i|².
   3. Soft-Decision Log-Likelihood Ratio (LLR) Calculation:
   * For each bit position b_m in {0, 1} within a symbol, computes the Max-Log-MAP LLR using post-equalization noise variance σ_eq²:
   * LLR(b_m) = (1 / σ_eq²) · ( min_{c ∈ S_m⁽⁰⁾} |X̂ - c|² - min_{c ∈ S_m⁽¹⁾} |X̂ - c|² )
   * Positive LLR indicates high confidence of bit 0; negative LLR indicates high confidence of bit 1; magnitude |LLR| represents reliability.
8.2 Descrambling, FEC Decoding & CRC Verification (Stage 7)
   1. Descrambling: Multiplies soft LLRs by (-1)^c(i) (or XORs hard bits with Gold sequence c(i)) to restore coded bit polarity.
   2. Forward Error Correction (FEC) Decoder:
   * Hamming(7,4) Syndrome Decoder: Computes 3-bit syndrome s = H · rᵀ to identify and flip any single-bit error per 7-bit block.
   * Viterbi Trellis Decoder (for Convolutional Code): Evaluates branch metrics over the 4-state trellis (00, 01, 10, 11) using either Hard Hamming distance or Soft LLR correlation, tracing back the survivor path to recover the original payload bits.
   3. CRC Checksum Verification Badge:
   * Recomputes the 8-bit or 16-bit CRC remainder over the decoded Transport Block:
   * Remainder == 0: Renders a green CRC PASS (ACK) status badge.
   * Remainder != 0: Renders a red CRC FAIL (NACK — HARQ Retransmission Requested) status badge.
   4. Dual BER Counters & ASCII Sink:
   * Reports both Pre-FEC Raw Channel BER and Post-FEC Decoded Transport Block BER, followed by the reconstructed ASCII text string with any residual errored characters highlighted.
